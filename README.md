CS student at TUM. Most of what I make sits between a coding agent and the rest of your machine: how agents share context, how they query data without guessing, how they decide which tool to call. The rest is small software I wanted for myself.

### Agent infrastructure

- **[synapse](https://github.com/VishiATChoudhary/synapse)**: Every coding agent on your machine, on one canvas. Link Claude Code, Codex, Gemini, Cursor and friends so they share context.
- **[theorem](https://github.com/VishiATChoudhary/theorem)**: A graph query and construction language for AI agents. Every query is verified whole before it runs, so it fails loudly instead of returning a plausible empty answer.
- **[graft](https://github.com/VishiATChoudhary/graft)**: Source control for agent-scale monorepos. Server-side changesets, want-only tiered fetch, lock-free landing. Written in Go.
- **[toolJev](https://github.com/VishiATChoudhary/toolJev)** · **[nanojev](https://github.com/VishiATChoudhary/nanojev)**: Tool selection by a calibrated decision model instead of an LLM. Typed decisions from a local model, no token generation. Benchmarked on MCPToolBench++, LiveMCPBench and When2Call.
- **[distillery](https://github.com/VishiATChoudhary/distillery)**: Pour a big model through an API, catch a small one. An autoresearch-style distillation loop.

### Things I use every day

- **[open-prism](https://github.com/VishiATChoudhary/open-prism)**: Open-source AI LaTeX editor and PDF viewer for the desktop.
- **[vishlang](https://github.com/VishiATChoudhary/vishlang)**: Train a model on your Mac to write the way you talk. Ships as a skill and an MCP `rewrite()` tool.
- **[reels](https://github.com/VishiATChoudhary/reels)**: Spec-driven 9:16 story reels in Remotion. One real voice, one song, the turning word lands on the drop.
- **[freebies](https://github.com/VishiATChoudhary/freebies)**: Local-first bookkeeping for German freelancers: invoices, receipts, bank imports and a Claude agent.
- **[Kali](https://github.com/VishiATChoudhary/Kali)**: Self-hosted Google Calendar sync. Many accounts, one week view, busy blockers copied across.
- **[browser-switcher](https://github.com/VishiATChoudhary/browser-switcher)**: Name Chrome profiles by email so agents open links in the right one.
- **[tum-rank](https://github.com/VishiATChoudhary/tum-rank)**: Course and professor ratings for TU Munich, by students.
